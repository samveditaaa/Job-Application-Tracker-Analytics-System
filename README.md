# 💼 Job Application Tracker & Analytics System

A Python and SQL-based application for tracking job applications, managing application statuses, and analyzing job search data.

## ✨ Features

- Add job applications
- View all applications
- Update application status
- Delete applications
- Store data using SQLite
- View job application analytics
- Find the most applied job role
- Calculate interview conversion rate
- Visualize application status using charts

## 🛠️ Technologies Used

- Python
- SQLite
- SQL
- Matplotlib
